# 😄 超链导航 HREF.HOST

[超链导航](https://href.host)（[href.host](https://href.host)）本质上就是一个普通而简单的导航网站。目前就是一个利用PHP开发的单页，甚至都称不上是一个网站，主要是分享一些免费或者好玩的网站。

其中我认为最拿得出手的就是各大虚拟币交易所的导航功能，原理非常简单，首先通过各大交易所的官方渠道（TG电报群、X、官网、客服、节点发布页等）收集官网备用链接，并且通过官网验证进行验证，当用户访问这个导航页面时，利用JS技术批量测试这些备用域名，最后直接跳转到当前网络能够正常访问或速度最快的备用域名链接，从而实现国内外网络环境均能够正常访问的交易所官网备用域名入口导航。以下为我们主要提供的几大交易所官网导航链接，欢迎大家体验。

- 👋 欧易OKX官网备用域名导航：[https://href.host/okx](https://href.host/okx)
- 🌱 币安Binance官网备用域名导航：[https://href.host/ba](https://href.host/ba)
- ⚡ 火币HTX官网备用域名导航：[https://href.host/htx](https://href.host/htx)
- 🤔 芝麻Gate官网备用域名导航：[https://href.host/gate](https://href.host/gate)
